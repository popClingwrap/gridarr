# gridarr 🎲

> Zero-dependency 2D grid engine using 1D flat buffers and lazy generators.

## Features
- 🚀 **High Performance:** Data stored as 1D flat buffer.
- ⚡ **Iterators:** Minimises memory allocations when slicing rows, columns, or subgrids.
- 🔄 **Coordinate Wrapping:** Built-in coordinate support.
- 📦 **Zero Dependencies:** Pure TypeScript compiled to ES modules with `.d.ts` types.

## Installation

```bash
npm install gridarr
